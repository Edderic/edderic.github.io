01 / Constrained multilingual NLP

Dataplor · Senior Machine Learning Engineer · 2024–2026

01

Name cleaningBERT · Token labeling
Python · AWS Batch

Reframe generation
as a labeling problem.

The important modeling decision was to narrow the output space to the source name.

A generative API cleaned multilingual business names, but inference cost reached $70,000 per run and generated output could contain invented tokens. For this task, the cleaned name could be constructed by retaining or removing source tokens.

I trained a BERT token-labeling model to predict KEEP or DROP and reconstructed the cleaned name from the original text. That constraint directly addressed the risk of introducing new name tokens.

Engineering

Multilingual examples, manual review, calibration, and batch inference on AWS Batch supported the production workflow.

Evaluation

Exact-match checks and error-slice review informed assessment. The reported outcome here is cost reduction; no numeric accuracy lift is claimed.

What this constraint solves—and where it needs care

Reconstructing from source text prevents invented name tokens. It does not, by itself, guarantee a correct name: the model can still remove useful text or retain clutter. Multilingual error review remains necessary. This formulation is best suited to cleanup tasks where the desired answer exists in the input, rather than tasks requiring correction or translation.

02 / Applied research to product

MasqFit · Research & Engineering Lead · 2024–present

Build the evidence.
Then build the experience.

Can facial measurements and fit-test outcomes help people select respirators that fit?

I secured a $50,000 grant from Vitalik Buterin’s Kanro Fund to investigate this question. I led participant recruitment, measurement and fit-test data collection, model development, and release of the open-source iOS app.

→
2 / ResearchModel development and held-out evaluation

3 / ProductFacial capture and respirator recommendations
Modeling

Experimented with neural networks and Bayesian logistic regression to predict fit, and designed methods to combine qualitative and quantitative fit evidence.

Measurement & product

ARKit supplies metric facial coordinates. The app computes defined facial measurement paths and passes the measurements into the recommendation workflow.

Evaluate on held-out people.

Repeated observations from the same participant call for participant-level separation. The October 29, 2026 research snapshot used five user-grouped folds.

*Internal retrospective snapshot, October 29, 2026. Mean across five user-grouped folds, conditional on a positive held-out outcome, ranking only the participant’s observed test rows. This is not a prospective success rate for a new user trying three recommended respirators.

Interpretation and remaining research questions

The ranking result measures whether the top three observed test rows include a positive held-out outcome for eligible participants. It does not establish performance on every untested respirator or broad population coverage. Measurement quality, uneven participant coverage, and prospective evaluation remain research questions.
